# Курс новичка Greenway — лендинг

Одностраничный адаптивный сайт-презентация курса новичка Greenway (20–24 октября 2026).

## Открыть сайт

При включённом GitHub Pages для данного репозитория с настройками **Deploy from a branch → main → /(root)** страница будет доступна по адресу:

https://iliavsevolodov.github.io/greenway_promo/newcomer-course-2026/

> Если GitHub Pages ещё не включён, открой **Settings → Pages** репозитория и настрой публикацию из ветки main и корневой папки. Дождись завершения публикации.

## Структура

- `index.html` — весь сайт: HTML, CSS и JavaScript, без сборки и дополнительных зависимостей.
- Адаптивный дизайн, программа пяти уроков (интерактивные вкладки), результаты, условия участия и FAQ.
- Модальное окно заявки: формирует текст для отправки партнёру Greenway через Telegram. **Не сохраняет и не отправляет персональные данные на сервер.**

## Подключение организатора

Внизу `index.html` найди строку:

```js
const CONTACT_URL = "";
```

Вставь ссылку на Telegram организатора, например `https://t.me/username`. Пока она не указана, посетитель может выбрать контакт Telegram самостоятельно или скопировать готовое сообщение.

Время уроков и ссылка на организатора не приведены в исходных материалах, поэтому не выдуманы.

## Источники содержания

Программа из пяти тем и дат 20–24 октября, предоставленная организатором, и исходная презентация «Курс новичка» (14 страниц). Условие участия — регистрация в команде и покупка продукта на 50 PV. Доходы не гарантируются.
